# VAYRO

Premium multi-tenant SaaS loyalty platform: digital stamp, points and visit cards, Apple Wallet
and Google Wallet passes, rewards, coupons, campaigns, analytics, and a Super Admin console.

**Brand:** Midnight Navy `#101828` · Electric Lime `#C6F36B` · Pure White `#FFFFFF`
