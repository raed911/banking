## Values VAYRO generates itself (never asked from you)

`VAYRO_ENCRYPTION_KEY`, `QR_SIGNING_SECRET`, `CRON_SECRET`. These are random secrets we
generate and store as environment variables in Vercel.

The Apple Wallet private key is also generated by VAYRO (certificate assistant) and stored encrypted;
Apple's public WWDR G4 intermediate certificate is downloaded from apple.com at runtime (or `APPLE_WWDR_PEM`).
